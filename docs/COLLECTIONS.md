# 专题集合维护规则

五个专题集合采用 `scripts/promote-student-candidates.mjs` 中的 `collectionMembers` 精选白名单，不是根据标签或分类自动扩张。

当前固定数量：

| 集合 | 数量 | 关键成员示例 |
|---|---:|---|
| 大学生常用 | 11 | PPT 制作、PDF 处理、复习卡片、简历检查、论文阅读 |
| 期末复习 | 5 | 复习卡片、复杂资料讲解、长期学习教练 |
| 论文与实验报告 | 5 | 单篇论文评议、多篇论文综述、结构化写作 |
| 实习求职 | 3 | 简历检查、Word、PPT |
| 编程入门 | 5 | 报错排查、Git 提交信息、复杂资料讲解、测试驱动开发 |

维护要求：

1. 新成员必须有明确的场景依据，并显式加入白名单；不能因为属于某个一级分类就自动进入专题。
2. 运行 `npm run promote:students` 会根据白名单重算集合关联，并在日志中报告集合数量及发生变化的记录 ID。
3. 修改白名单后必须同步更新数量回归测试和本文件；不得静默扩大或缩减集合。
4. 专题入选不表示来源、安全或功能已经审核通过；条目的审核状态仍以 `reviewStatus` 为准。
