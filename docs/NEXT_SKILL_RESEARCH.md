# 下一批 Skill 调研清单

> 状态：仅为需求缺口与调研方向，不是已经核验或准备直接导入的 Skill。

## 优先方向

1. **通用数据分析与科研绘图**：面向 CSV、Excel 和实验结果的数据清洗、统计分析与图表生成。
2. **参考文献与引用核验**：核对作者、标题、DOI、出版信息和引用格式，重点防止不存在或信息错误的引用。
3. **考试大纲与考点提炼**：把课件、考试大纲和复习笔记转成考点清单、重点解释与针对性练习。
4. **模拟面试与求职复盘**：根据目标岗位进行模拟提问、回答反馈、薄弱点分析和下一轮练习。

## 每个候选进入 staging 前必须确认

- 原始 `SKILL.md` 或等价的一手说明可以访问，并与候选 ID 对应。
- 仓库、作者、许可证、运行依赖和兼容平台有可追溯来源。
- 安装命令只有在原始来源可以核实时才填写；否则保持 `installCommand: null` 并填写 `installNote`。
- 脚本权限、联网行为、读写文件范围和敏感数据风险已经静态检查。
- 示例明确标记为演示、推断或实测，不伪造成功率、截图和运行结果。
- 先进入 staging 并保持 `reviewStatus: pending`，通过人工审核后再决定是否进入正式目录。
