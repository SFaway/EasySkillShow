# EasySkillShow · MVP PRD

## 一、问题与目标

目标用户：已经使用 ChatGPT/Codex 等 AI 工具，但不了解 Skill 或不确定如何选择 Skill 的中文用户；同时兼容熟悉 Skill 名称的开发者。

当前待验证的假设：英文、专业术语、低可视化会增加 Skill 的理解和探索成本。也可能存在没有使用需求等其他原因，不能把“周围同学不知道 Skill”直接当作整个市场规模的证明。

产品承诺：**输入想做的任务 → 找到候选 Skill → 用通俗中文理解能力和限制 → 查看可追溯来源与安装方式。**

## 二、页面架构

### 一级页面 / Skill 发现

- 顶栏：品牌、发现、新手入门、关于；参考 PCL 蓝白色的工具式界面。
- 左栏：全部、发现工具、办公文档、网页设计、营销创作、可视化、Skill 开发、收藏。
- 搜索区：名称/用途、分类、排序、常用需求快捷入口。
- 列表：中文名称、英文原名、通俗说明、仓库、分类、来源核实状态。
- 无结果：清楚反馈没有收录，而不是编造查询结果。

### 二级页面 / Skill 详情

- 顶部：返回、中文名称、原名、简介、分类、作者源仓库、来源和安装命令。
- 内容标签：功能介绍 / 使用示例 / 安装方式 / 限制与来源。
- 真实截图只有在审计素材来源和功能测试后才加入；否则显示「演示性示例，非实测」。

### v0.2 信息分层

- 详情的「功能介绍」和「使用示例」支持**简明版 / 详细版**切换。
- 简明版复用已有一句话介绍、典型场景、用户输入与可能输出，降低新手理解成本。
- 详细版补充完整说明、工作流程、前置依赖、使用步骤、产物形式和能力边界。新增字段缺失时，明确提示待完善，不得伪装为真实执行结果。
- 这不是两个数据库，而是同一条 Skill 数据的不同深度展示。列表页保持高信息密度，不因为详细层变长。

## 三、最小流程与验收标准

1. 输入「PPT」可以找到 `anthropics/skills/pptx`，进入详情后看到用途、示例、限制、安装命令与真实来源。
2. 输入「广告文案」可以找到 `ad-creative`。
3. 按分类筛选后只显示相应 Skill。
4. 收藏 Skill 后刷新浏览器仍然可以查看收藏（本机 LocalStorage）。
5. 点击「Skill 是什么」能看到新手解释。
6. 点击「复制安装命令」只复制字符串，不自动执行。
7. 访问 API 可以获得同一份数据；不同 ID 返回对应条目，未知 ID 返回 404。
8. 页面宽度较窄时仍可操作搜索、浏览与详情。
9. 断开第三方 Skill 服务后，本地目录仍能正常运行。
10. 在二级页的「功能介绍」「使用示例」切换简明版/详细版，原有输入和输出不会丢失，未完善的详细数据有明确提示。
11. 使用 `--update-existing` 可以对已有 Skill 进行干运行检查，经过确认才执行 `--write`，写入前会保存备份。

## 四、第一版明确不做

不做用户登录、全量同步、AI 翻译、自动执行不可信脚本、真正一键安装、在线分享图床、社区评论以及自动生成真实 Skill 运行效果图。

## 五、面试作品集所需验证

建议找 6～10 名目标用户完成同一组任务，对比原始 Skill 英文页面和 EasySkillShow 的中文详情：

- 找到适合任务的 Skill 所需时间。
- 能否正确说出 Skill 的作用、使用条件和限制。
- 能否定位原作者来源及安装方式。
- 误解率、主观易用性评分。

要记录原始结果，不要把预计改善作为实际实验结论。
