# EasySkillShow v0.7 发布前体验审查

审查日期：2026-10-21

## 范围与方法

本次检查覆盖“从任务首页找到 Skill、查看详情、加入并打开对比、请求失败后恢复”四条核心路径。方法包括源代码走查、Nielsen 启发式检查、异常状态清单、自动化回归测试和本地 HTTP/API 检查。由于当前自动化浏览器未获授权读取 localhost 页面，桌面、移动端和键盘的可视化人工验收未被记录为通过。

## 反模式结论

结论：Clean。未发现虚假稀缺、诱导同意、伪造社会证明、强制连续使用或不透明个性化。推荐区明确说明筛选依据，来源核对、安装命令和 Codex 实测状态保持独立。

## 优先问题与处理

- P0：无。
- P1：快速连续改变筛选条件时，较早的请求可能晚于新请求返回并覆盖新结果。已通过请求序号隔离修复。
- P1：详情接口超时和 404 都显示“没找到”，会误导用户。现已分别显示“详情暂时无法读取”和“没找到这个 Skill”，并提供对应恢复操作。
- P2：浏览器禁止本地保存时，收藏与对比操作可能抛错。现已降级为当前页面可用，并明确提示未能持久保存。
- P2：页面、健康接口、package.json 和 README 的版本号不一致。现已统一为 v0.7 / 0.7.0。

## 启发式结论

- H1 系统状态可见性：Holds。加载、收藏、对比、复制、错误和重试均有反馈。
- H2 符合现实语言：Holds。主要操作使用任务语言，并解释 Skill、来源核对和实测差异。
- H3 用户控制与自由：Holds。可返回并保留列表位置，可清除收藏外的本地辅助状态。
- H4 一致性：Holds。列表、详情和对比使用一致的质量与证据标签。
- H5 错误预防：Holds。对比限制为 3 项，外部命令只复制不执行。
- H6 识别优于记忆：Holds。保留最近浏览、任务入口、筛选摘要和分类导航。
- H7 灵活与高效：Holds。支持搜索、任务入口、分类、专题、收藏、对比和详情标签键盘切换。
- H8 简洁设计：Holds。首页优先任务和精选，完整目录采用分批展示。
- H9 错误诊断与恢复：Holds。目录、详情和首次启动失败均给出原因和恢复操作。

## 核心任务走查

1. 从任务入口找到 Skill：路径明确，任务卡 → 筛选结果 → 条目详情，无死路。
2. 判断是否值得使用：质量等级、来源、Codex 状态、安装状态和风险分区呈现，不要求用户凭名称猜测。
3. 对比多个 Skill：可在列表选择 2–3 项，比较用途、依赖、安装、许可证和风险；不足 2 项时按钮禁用并有数量反馈。
4. 从失败中恢复：目录超时可重试；详情读取失败可重试；404 可返回目录；本地保存失败不会中断页面。

## 保留的验证缺口

- 尚无真实目标用户可用性测试，不能宣称已经证明“降低理解成本”。
- 未完成自动化视觉回归、不同浏览器兼容性测试和屏幕阅读器实机测试。
- 外部 Skill 的安装、安全、维护和功能可用性不属于本项目验证结果。
