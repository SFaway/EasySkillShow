EasySkillShow v0.3 产品改进计划
生成日期：2026-10-20

产品目标
把 EasySkillShow 从“展示 Skill 的目录”升级为“帮助大学生按任务选对 Skill，并安全开始第一次使用”的决策工具。

约束
1. 不继续批量扩充 Skill 数量。
2. 不自动执行安装命令或外部脚本。
3. 不把来源核对描述为安全、兼容性或功能实测通过。
4. 保留完整目录、现有分类、专题集合和未通过候选。

阶段一：任务式首页（P1）
[x] 首页优先展示大学生常见任务，而不是直接铺开 119 条记录。
[x] 提供论文与报告、期末复习、PPT、数据分析、实习求职、编程入门六个任务入口。
[x] 首页推荐只展示内容质量较高且来源已核对的少量条目。
[x] 保留“浏览全部 119 条”入口和原有搜索、分类能力。

阶段二：内容质量等级（P1）
[x] 区分基础收录、深度审核、实际验证三个等级。
[x] 在列表和详情页显示质量等级及含义。
[x] 基础收录条目可搜索，但不进入首页推荐。
[x] 保持 Codex 实测状态、命令来源状态与质量等级相互独立。

阶段三：候选对比（P1）
[x] 支持选择最多 3 个 Skill。
[x] 对比用途、质量等级、Codex 状态、依赖、安装命令、许可证和风险。
[x] 支持移除候选和清空对比。
[x] 对比选择保存在本地浏览器，不引入账号系统。

阶段四：首次使用闭环（P1）
[x] 详情页新增“开始使用”入口。
[x] 根据证据状态展示检查平台、确认依赖、运行安全测试任务三个步骤。
[x] 没有可靠安装命令时只引导查看原作者说明。
[x] 允许复制安全测试提示词，但明确复制不等于安装或验证成功。

阶段五：真实状态与回归测试（P2）
[x] 加载目录时显示明确反馈。
[x] 为首页推荐、任务入口、质量等级、对比和首次使用流程增加自动化测试。
[x] 运行 npm run check 与 npm test。
[x] 浏览器检查桌面首页、全部目录、对比页和一个详情页。

后续用户研究（不在本轮伪造结果）
[ ] 邀请 5—8 位大学生完成找 Skill、判断依赖和开始使用三个任务。
[ ] 记录两分钟内选出候选的比例、状态理解正确率和主要犹豫点。
[ ] 根据真实结果决定是否增加登录、评分或自动安装功能。
